🎵 About This Project

Why Mood Melody?

Music is deeply tied to emotions. Mood Melody bridges the gap between how you feel and what you listen to — creating an intelligent, personal, and immersive music discovery experience.

✨ Key Features

🎭

8-Mood Detection System

Detect Happy, Sad, Angry, Relaxed, Romantic, Focused, Energetic, and Heartbroken states through clicks, voice, or text input.

🎤

Voice Recognition

Speak naturally and our Web Speech API integration automatically detects your mood from conversational phrases.

🌐

Real-Time API Music

Songs are fetched live from Last.fm and Deezer APIs, ensuring up-to-date and relevant recommendations.

💾

Persistent Favorites

Save songs to your local favorites that persist across sessions using localStorage — no backend required.

🌓

Dark / Light Mode

Seamlessly toggle between a premium dark and a clean light theme. Your preference is saved automatically.

📱

Fully Responsive

Works beautifully on mobile, tablet, and desktop with a fluid, adaptive layout.

❓ FAQ

How does mood detection work? ▼
You can select a mood from 8 options, use voice recognition to speak naturally (e.g., "I feel happy today"), or type your feelings in the text box. The system maps keywords to moods and fetches music accordingly.
Are the songs real? ▼
Yes! Songs are fetched live from the Last.fm API using mood-based tags. Play buttons redirect to Deezer for actual audio playback. A Last.fm API key is embedded for demo purposes.
Is my data stored online? ▼
No. All your favorites, mood history, and profile data is stored locally in your browser using localStorage. Nothing is sent to any server.
Does voice recognition require permissions? ▼
Yes, your browser will ask for microphone access when you click "Speak Your Mood." This uses the browser's built-in Web Speech API and requires HTTPS or localhost.
What are the future improvements? ▼
Planned features include: Spotify OAuth integration, facial expression mood detection via webcam, social sharing, collaborative playlists, and a backend for cross-device sync.
